## 🎵 Adding Background Music

1. Add MP3 file to project folder
2. Update `<audio>` tag with filename:
   ```html
   <source src="your-music.mp3" type="audio/mpeg">
   ```
3. Guests can play/pause using floating button

**Tips:**
- Keep file size under 5MB
- Use compressed MP3 (128-192 kbps)
- Choose romantic, non-intrusive music

## 💡 Tips & Best Practices

### Content:
- Keep names and text concise
- Use high-quality images (if added)
- Test all links before sharing
- Update countdown date accurately

### Design:
- Don't change too many colors
- Maintain visual hierarchy
- Test on multiple screen sizes
- Ensure text is readable

### Deployment:
- Use HTTPS (free with Netlify/Vercel)
- Test the live link yourself first
- Share with 1-2 people before mass sending
- Keep backup of original files

### Sharing:
- Use URL shorteners (bit.ly, tinyurl)
- Create QR code for printed invitations
- Send personalized messages on WhatsApp
- Track responses via RSVP form
